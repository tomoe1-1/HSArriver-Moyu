# HSArriver Turbo 桌面软件

**双击项目根目录的 `HSArriver.exe` 即可。** 不需要浏览器、终端或 Node 服务。

软件是 Windows x64 原生窗口 + WebView2；界面为 HSArriver Turbo 自带的工作台样式和品牌图标。
启动时选择本项目的 Python 3.12 环境，直接启动后端并等待就绪事件，再载入内嵌界面。
已有同项目后端时复用，不重复拉起。

## 功能与安全边界

- 原生工具栏：启动 / 停止 / 重启后端、刷新界面、启动日志、管理员重新打开。
- 软件启动**只启动后端服务**：不恢复上次定时任务、不打开浏览器、不自动匹配或出牌，
  也不定时抢走游戏前台；对战仍由用户在界面明确启动。
- 默认不自动提权。游戏操作需要管理员时，点击「以管理员重新打开」，自行确认 Windows UAC。
- 「环境自检 → 管理员权限」也有「管理员运行」按钮，会同步提权前端与后端，
  无需手动运行 Python。页面与原生工具栏分别显示前端 / 后端权限，不以“前端已提权”假装后端达标。
- 已以管理员身份打开前端，但检测到普通权限后端时，会征求确认后重新拉起管理员后端；
  若后端已是管理员，仅提升前端时保留后端。
- 停止、重启和退出会先提示后果并确认，只结束本软件启动的后端，不结束炉石。
- 复用外部启动的后端时，不擅自结束它。只有用户明确确认权限修复和中止自动化后，
  才通过带随机 token 的后端自停接口退出同项目后端，绝不强制结束外部进程。
- 前端只加载校验过的本项目 `127.0.0.1` 后端，外部链接交给默认浏览器；不开放公网端口。
- 日志在 `log/desktop/desktop.log`，WebView2 用户数据也在 `log/desktop/`，不进仓库。

需要保留整个项目目录、`.venv` 和 `desktop/runtime`，不要只移动一个 EXE。
本机已安装 Edge WebView2 Runtime；其他机器需要它以及项目的 Python 后端环境。

## 构建

```powershell
powershell -File desktop/build.ps1
```

使用 Windows 自带的 .NET Framework C# 编译器，按固定版本获取官方 WebView2 SDK；
没有新增 Python 运行依赖，也不需要 Flutter / Visual Studio / .NET SDK。
首次图标渲染需要构建机的 Playwright（可通过 `PLAYWRIGHT_MODULE` 指定），
已安装的软件运行不需要它。

真实连接冒烟测试（不操作游戏）：

```powershell
.\HSArriver.exe --smoke-test
```

测试会启动自己的待机后端、验证内嵌页面连接、保存预览与结果到 `log/desktop/`，
然后仅关闭自身创建的后端。默认双击启动则保持软件运行。
